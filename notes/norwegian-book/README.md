# Norwegian Book Notes: *Etterisolering av småhus*

Notes on what I learn from the Norwegian book *Etterisolering av småhus* (Retrofit insulation of small houses), one note per chapter/section.

## Note format

Each note contains:

1. **Pictures**: the photos of the book pages (stored in `images/`).
2. **Norwegian text**: the text extracted from the pictures.
3. **English translation**: a translation of the Norwegian text.
4. **Q&A**: questions I asked about the section, with the answers.
